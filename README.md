# 🎮 C++ OOP Game

A C++ desktop game project created as an object-oriented programming exercise.

## 🧠 What It Demonstrates

- Object-oriented programming in C++
- Game-loop design
- Keyboard/input-driven interaction
- Audio assets
- Basic desktop game development

## 📁 Structure

    game/
    ├── game.cpp
    ├── ARIALI.TTF
    ├── land.wav
    ├── line.wav
    └── README.md

## 🚀 Getting Started

    git clone https://github.com/cypher2k22/game.git
    cd game

Compile the source using the graphics/audio libraries required by the project.
